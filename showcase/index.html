Reconstruct identities before splitting

A beat-level CSV cannot establish who appears in training and test. The raw manifest preserves subject groups and keeps records 201/202 together. Every split supports N/S/V/F/Q, including paced subjects.

Choose the checkpoint before opening the test

The CNN trains for 24 epochs with class-weighted cross entropy. Unweighted validation loss selects epoch 9. The saved test predictions, confusion matrix and independent audit support the reported scores.

Saved replay data · not a second benchmark

The replay contains ten examples from each class. It is balanced for demonstration and does not represent test prevalence. Softmax values are uncalibrated model scores.

A model-backed replay interface

Start · pause · reset · simulated alerts

Screenshot from the browser-verified demo. The local server runs the exported NumPy model on each requested beat. Run it locally.

Reference peaks are supplied by the dataset, and centered windows need half a second after the beat. The interface replays recordings. It does not acquire live ECG, detect beats or provide clinical alarms.

Subject-adversarial learning: promising, rejected

A separate 18-cell experiment improved mean four-class macro F1 on MIT and INCART. It also increased MIT fusion false positives beyond the frozen allowance, so I retained the existing reference. This keeps the decision tied to the agreed criterion.
